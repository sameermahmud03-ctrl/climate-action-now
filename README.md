# America on Tech Website: Climate Action Now

A multi-page website for a fictional climate nonprofit, **Climate Action Now**, built by our group for the America on Tech program. It was built with HTML, CSS, and Bootstrap 5.

## Pages
- `index.html`: home page (mission, donations, sponsor carousel)
- `About.html`: team, values, impact, and events calendar
- `news.html`: climate news articles
- `services.html`: services the organization offers
- `support.html`: upcoming events and a sign-up form

## Notes
- Climate Action Now and its team members, address, phone number, and email are **fictional** and used as placeholders.
- All pictures (logo, news thumbnails, service and event images, page headers) are original illustrations drawn for this project as SVG files. No outside photos are used.
- The news cards are short summaries written in our own words, each with a link to the original article.
- The sponsors (Evergreen Foundation, Bright Future Fund, Blue Planet Alliance) are fictional.
- Every page has a footer note that this is a fictional school project, and the Donate buttons and sign-up form do not work.
- The four short videos (`donations.mp4`, `mission.mp4`, `export.mp4`, `export-3.mp4`) are slideshows made from the original illustrations. The pages also reference a `script.js` that is not included (not needed).

## Tech
HTML, CSS, Bootstrap 5, Google Fonts, Friconix icons
